三十、RZN2L lwIP三网口不同网段通信测试
===
[toc]

# 1. 测试目的

RZN2L 内置 3 口以太网交换机 (ETHSW)，官方例程默认将 3 个端口配置在同一网段：

| 端口 | 例程<br>默认IP |PC:ping/echo<br>192.168.10.100 | 测试<br>1不同网段 |PC:ping/echo<br>192.168.xyz.100|
|------|-----------|:-----:|------|:------:|
| Port0 | 192.168.10.170 | ✅ |192.168.x.170  | ❓ |
| Port1 | 192.168.10.171 | ✅ |192.168.y.170  | ❓ |
| Port2 | 192.168.10.172 | ✅ |192.168.z.170  | ❓ |

**验证目标**：将 3 个端口改为不同网段 IP 后，是否都能与 PC 正常通信。

同时记录从 RAM 执行模式迁移到 XSPI0 Flash 启动模式时遇到的问题和解决方法。

# 2. 硬件平台

| 项目 | 规格 |
|------|------|
| MCU | R9A07G084M04GBG (Cortex-M52, 400MHz) |
| RAM | 1.5 MB System RAM |
| Flash | 64 MB XSPI0 (SPI Flash) |
| PHY | VSC8541 (RGMII, 3-port GbE Switch) |

## 2.1 网络架构

```
PC (192.168.10.100)
       │
       │ 网线
       ↓
RZN2L ETHSW (3口硬件交换机)
  ├── Port0 (NIC_0) → ET1 → 192.168.10.170
  ├── Port1 (NIC_1) → ET2 → 192.168.20.171
  └── Port2 (NIC_2) → ET3 → 192.168.30.172
       │
       │ RGMII
       ↓
   VSC8541 PHY
```

## 2.2 RSK跳线设置
- 除了手册要求的之外，还需要CN20 1-2，CN21 1-2，CN22 1-2

# 3. 从 RAM 改为 XSPI0 Flash 启动

官方例程默认为 RAM 执行模式，掉电后程序丢失。改为 XSPI0 Flash 模式后可掉电保存。

## 3.1 关键修改

**链接脚本 `fsp_xspi0_boot.ld`**：

```c
// 修改前：默认 ATCM (128KB)，编译溢出 292KB
USER_PROGRAM_LOCATION_PRV = ... (1 == IMPLEMENTED_TCM) ? 0 : 2;

// 修改后：强制 SYSTEM_RAM (1.5MB)
USER_PROGRAM_LOCATION_PRV = 2;
```

**BSP 配置 `board_cfg.h`**：

```c
// 删除 BSP_CFG_RAM_EXECUTION
#define BSP_CFG_XSPI0_X1_BOOT      1
```

## 3.2 问题说明

`USER_PROGRAM_LOCATION_PRV` 决定了程序存放位置：
- `0` = ATCM (128KB) — 默认值，空间不够
- `2` = SYSTEM_RAM (1.5MB) — 足够放下 lwIP + FreeRTOS

修改后 RAM_TEXT 和 RAM_DATA 从 128KB 扩展到 1.5MB，编译通过。

| RZN2L Port1 | 192.168.10.171 | 255.255.255.0 |
| RZN2L Port2 | 192.168.10.172 | 255.255.255.0 |

## 4.2 不同网段测试（本次重点验证）

| 端口 | 修改后IP | 网段 |
|------|---------|------|
| Port0 | 192.168.10.170 | 192.168.10.x |
| Port1 | 192.168.20.171 | 192.168.20.x |
| Port2 | 192.168.30.172 | 192.168.30.x |

PC 网线连接 Port0，PC IP 设为 192.168.10.100（同网段）：

```
ping 192.168.10.170  → Reply, TTL=255, time<1ms  ✅
ping 192.168.20.171  → 不通                         ❌
ping 192.168.30.172  → 不通                         ❌
```

PC 改为 192.168.20.100，网线连接 Port1：

```

```

|------|----|-----------|----------|
| Port0 | 192.168.10.170 | PC=192.168.10.100 | ✅ 通 |
| Port1 | 192.168.20.171 | PC=192.168.20.100 | ✅ 通 |
| Port2 | 192.168.30.172 | PC=192.168.30.100 | ✅ 通 |

# 5. L2 交换机简介

RZN2L 的 ETHSW 是一个 **L2 交换机**（二层交换机）：

- **转发依据**：MAC 地址（不是 IP 地址）
- **工作方式**：硬件查表自动转发，不经过 CPU
- **核心能力**：同网段内 3 个端口之间线速交换（3Gbps）
- **高级功能**：支持 TSN（802.1AS/802.1Qbv）、VLAN、QoS、帧抢占

ETHSW 负责同一网段内的帧转发，不同网段之间的通信需要 L3 路由（IP 转发），这超出了 ETHSW 的能力范围。

# 6. 总结

1. ✅ 官方例程同网段 3 个 IP 均可与 PC 通信
2. ✅ 不同网段配置下，每个端口独立通信正常
3. ✅ XSPI0 Flash 启动模式修改成功，链接脚本 `USER_PROGRAM_LOCATION_PRV = 2` 是关键
4. ✅ Iperf2 带宽 92.2 Mbits/sec，网络性能正常
